## 1. Alfabeto

Agrupado por som, que é a forma mais fácil de memorizar:

| Som | Letras | Como soa (aproximado) |
|---|---|---|
| /eɪ/ | A, H, J, K | "ei", "eitch", "djei", "kei" |
| /iː/ | B, C, D, E, G, P, T, V, Z* | "bi", "si", "di", "i", "dji", "pi", "ti", "vi", "zi" |
| /ɛ/ | F, L, M, N, S, X | "éf", "él", "ém", "én", "és", "éks" |
| /aɪ/ | I, Y | "ai", "uai" |
| /oʊ/ | O | "ou" |
| /uː/ | Q, U, W | "kiu", "iu", "dâbol-iu" |
| /ɑːr/ | R | "ar" |

\* Z = "zi" no inglês americano e "zed" no britânico.

### ⚠️ As que mais confundem

| Letra | Erro comum | Correto |
|---|---|---|
| **E** | "é" | "i" |
| **I** | "i" | "ai" |
| **A** | "a" | "ei" |
| **G** | "gê" | "dji" |
| **J** | "jota" | "djei" |
| **R** | "érre" | "ar" |

> 💡 **G** e **J** trocam de lugar em relação ao que parece: G = "dji", J = "djei".

## 2. Soletrar e-mail e links

| Símbolo | Em inglês |
|---|---|
| @ | at |
| . | dot |
| _ | underscore |
| - | dash / hyphen |
| / | slash |
| letras dobradas | "double" (ex.: *double L*) |

Exemplo: `john.doe@gmail.com` → *john dot doe at gmail dot com*
Exemplo: `github.com/user` → *github dot com slash user*

## 3. Sons difíceis para brasileiros

### TH
- **/θ/** (sopro, sem voz): *think, thanks, three*
- **/ð/** (com voz): *this, the, they*

Coloque a ponta da língua **entre os dentes** e sopre. Não é "f", "t" nem "d".

### H no início = sopro (não é "r")
*hello, house, hot* — como se embaçasse um vidro.

### R no início = não vibra
*red, right, run* — a língua não encosta no céu da boca. **Não** é o "r" de "rato".

### Vogal no fim que não existe
Brasileiros tendem a pôr um "i" no fim: ~~"bigui"~~ → *big*, ~~"jobi"~~ → *job*, ~~"chequi"~~ → *check*.
